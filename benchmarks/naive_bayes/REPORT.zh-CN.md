# 0.4：用用户级分类器替换内部 Bayes

本轮交付 `gaussian_naive_bayes`，删除原 ABO 联合选择率估计实现。新算法是真正的监督分类器，而不是把旧 `predict_joint` 换名字。它不是通用贝叶斯网络，不接受 DAG/MCV/分箱参数。

## 用户能力

第一列标签，后续数值/布尔标量或固定维度浮点数组；支持二分类、多分类和原始 PG 类型标签。`predict_label` 返回类别，`predict_proba` 返回归一化后验概率，`predict_log_proba` 返回稳定的对数后验。数组顺序由 `class_labels` 确定。JSON 模型、权限/RLS、事务回滚、模型缓存、备份恢复和显式模型 DDL 均复用既有框架。

## 实现与数值边界

C11 + PG 运行时，无新增训练库。Welford 计算各类别/全局总体方差；显式相对平滑和绝对方差下限。先验可选经验频率或均匀分布。使用 logsumexp 归一化，普通预测复用现有 SIMD 平方范数内核。远尾部样本以逐特征的似然差避免巨大共同惩罚项相减丢失有效位数。

概率之和为1不等于经过校准。强相关、稀疏或类内接近常量的特征可能导致极度自信的错误预测；不能把数值稳定性当成统计假设正确。暂不提供类别型特征、Multinomial NB、任意网络结构学习或在线 partial_fit。

## 实际验证

本地 PostgreSQL 18.0、GCC14.2、AMD EPYC7763、native-only/SIMD AVX2。完整集成测试通过，包含原有原生算法、NULL/常量/数组/类型标签、权限和RLS、回滚、源查询只执行一次、强制溢写、模型预算、损坏模型、升级与逻辑备份恢复。

独立标准库两遍均值/方差及后验公式 oracle 完成792项数值比较，覆盖 SIMD off/portable/auto，在新连接和备份恢复后再次验证。不是运行外部 sklearn 估计器。

复用既有公开分类数据的三个冻结划分（42/2024/7），只执行当前新分类器。共12组，一次预热、三次训练计时，无调参；预处理参数与训练/测试行沿用冻结输入，没有重跑其他基线。

| 数据集 | Accuracy均值±样本标准差 | 平均log loss | 训练中位数ms |
|---|---:|---:|---:|
| Banknote | 84.14% ± 2.15个百分点 | 0.3145 | 2.725 |
| Breast Cancer | 90.06% ± 3.65个百分点 | 1.0768 | 3.072 |
| Digits | 75.58% ± 2.44个百分点 | 1.4770×10^9 | 16.225 |
| Wine | 94.44% ± 4.81个百分点 | 0.2030 | 2.389 |

Digits 的巨大 log loss 如实保留：模型在类内近零方差特征上对错误类别过度自信。它说明默认Gaussian假设/平滑不适合这组数据，不是可作为“置信度”的可靠概率。没有为改善已查看的holdout分数而反复调整平滑。小样本划分间波动不构成显著性检验。

对每个模型分开核查训练与推理：独立两遍统计验证均值/方差（容差1e-12）；再从实际序列化参数独立计算所有holdout行的后验，避免将不同拟合累加顺序误当推理错误。最大概率差约1.82e-14；远尾部极大负对数概率的绝对差可到3.05e-4，验证使用相对1e-10加绝对1e-8容差，而非声称逐位一致。类别与独立公式全部一致。

训练计时包含数据准备/统计/训练集诊断/持久化，不包含客户端启动和COPY导入。没有与历史不同机器的耗时宣称加速比、没有峰值内存或并发结论。原始SQL、模型、逐行预测、参数与日志在对话证据包；仓库保留复现脚本和汇总。

## 升级

安装新库、结束旧连接、重新连接后执行 `ALTER EXTENSION pg_db4ai UPDATE TO '0.4.0';`。原 `bayes_net_internal` 不再训练或推理；旧模型原样保留，可解释、导出和删除，不自动改成监督模型。新安装不提供 `predict_joint`；升级以RESTRICT删除该函数，存在用户依赖时会阻止升级，不使用CASCADE。

详见 ../../docs/NAIVE_BAYES.md。`validate.py` 只应针对可丢弃的测试数据库，写入/重建固定的 nb_validate_train、nb_validate_test 测试表。
